# Day 8 — Job Application Tracker (Python CLI)

A command-line job application tracker built in Python that allows users to log, store, and review job applications with persistent data storage.

This capstone project demonstrates practical file handling, data persistence, user input validation, and clean CLI design — all highly relevant to support, operations, and junior developer–adjacent roles.

---

## 🚀 Features

- Add new job applications with:
  - Company name
  - Job title
  - Location / Remote
  - Application status
  - Notes
- View all saved applications in a clean, readable format
- Persistent storage using a local JSON file
- Gracefully handles missing or corrupted data files
- Simple, intuitive command-line interface

---

## 🧠 Skills Demonstrated

- File I/O with JSON persistence
- Defensive programming and error handling
- Dictionary and list-based data modeling
- CLI application design
- User input handling and validation
- Clean, modular Python code
- Git & GitHub workflow best practices
